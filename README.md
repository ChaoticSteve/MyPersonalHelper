# Salary Tracker Web (Django)

## Описание проекта

Веб-приложение для автоматизации расчёта заработной платы преподавателя с возможностью дальнейшего масштабирования под многопользовательскую систему.

Проект является развитием десктопного приложения на PyQt6 и переносит его функциональность в веб-среду с использованием Django.

Приложение позволяет:

* учитывать проведённые занятия через браузер
* автоматически рассчитывать доход
* формировать помесячную статистику
* просматривать разбивку по дням
* закладывать основу для пользовательских настроек и расширенной аналитики

---

## Цель проекта

Проект разработан как следующий этап развития локального инструмента учёта зарплаты — с целью создания гибкой системы, которая:

* поддерживает нескольких пользователей
* позволяет настраивать правила расчёта
* предоставляет расширенную аналитику и отчётность

---

## Функциональные возможности

### Ввод данных

* дата занятия
* тип занятия:

  * групповой
  * индивидуальный
  * мастер-класс
  * отработка
* формат: онлайн / оффлайн
* количество учеников (для групп)

### Расчёт заработной платы

* автоматический расчёт стоимости занятия
* логика расчёта инкапсулирована в модели
* разные тарифы в зависимости от:

  * формата (онлайн / оффлайн)
  * типа занятия
  * количества учеников

### Аналитика

* расчёт заработной платы за месяц
* ежедневная разбивка дохода
* отображение всех занятий за выбранный период

### Работа с данными

* хранение данных через Django ORM
* автоматический расчёт суммы при сохранении
* валидация данных на уровне модели
* фильтрация по месяцу и году

## Логика расчёта

Стоимость занятия рассчитывается автоматически при сохранении записи на основе:

* формата занятия (онлайн / оффлайн)
* типа занятия
* количества учеников (для групп)

Реализована система валидации и расчёта, обеспечивающая корректность данных и единый источник бизнес-логики.

## Установка и запуск

### Установка зависимостей

```bash
pip install django python-dotenv django-environ
```

### Настройка окружения

Создайте файл .env в корне проекта:

```
SECRET_KEY=your_secret_key
DEBUG=True
DB_ENGINE=django.db.backends.sqlite3
DB_NAME=db.sqlite3
```

### Применение миграций

```bash
python manage.py migrate
```

### Запуск приложения

```bash
python manage.py runserver
```
